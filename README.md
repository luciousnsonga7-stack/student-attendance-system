# Student Attendance Management System

## Project Description

The Student Attendance Management System is a simple web-based application designed to help teachers manage student attendance electronically.

## Features

- Student registration

- Mark students as Present or Absent

- Search for students

- Remove student records

- View attendance statistics

- Responsive design

- Browser Local Storage

## Technologies Used

- HTML5

- CSS3

- JavaScript

## How to Run

1. Open the project repository.

2. Download or clone the project.

3. Open `index.html` in a web browser.

4. Register students and manage their attendance.
